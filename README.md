## 去重与混剪技术原理（概述）

主流平台（微信视频号 / 抖音 / TikTok / Facebook）普遍采用「视觉 + 音频 + 时序」三路相似度检测来识别重复内容。帧码宝的去重与混剪方案，正是围绕这三路指纹分别做扰动，在不破坏观感的前提下降低查重命中：

- **视觉指纹**：通过局部像素位移、边缘区域混淆、画面叠层与色调微扰，改变画面的视觉特征分布，让平台的图像相似度算法判为「新内容」。
- **音频指纹**：借助人声分离 + BGM 替换 + 节奏微变速，改变音频的哈希特征，规避音频重复命中。
- **时序指纹**：通过抽帧 / 插帧、关键帧重排与整体微变速，破坏帧序列的连续性特征。

> 说明：以上为行业通用的去重思路概述，具体参数与实现细节属于产品核心能力，不对外公开。
