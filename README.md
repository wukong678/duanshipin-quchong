## 功能概览

### 微信视频号去重

**微信视频号去重** 是帧码宝针对微信视频号平台查重机制打造的核心能力。通过鲇鱼插针式画面补偿（色差 / free box / 极性 / 量化扰动 / 时域噪 / PSNR 自检）、抽帧微旋转、叠层装饰等多重手段，让搬运与二创视频在视频号原创检测中更稳定通过。支持 N 卡与 Intel 核显硬件编码，自动回落 CPU，不挑机器。

### 短剧去重 / 短剧搬运 / 短剧混剪

### 视频去重 / 视频混剪

通用**视频去重**与**视频混剪**能力，覆盖影视二创、搬运、重混剪等自媒体场景：抽帧、微旋转、微缩放、中心裁切、花边装饰、色调微扰、随机码率等多维去重；混剪支持自动选段、转场、氛围字幕，批量产出高完播结构成品。
