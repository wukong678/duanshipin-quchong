# 帧码宝 — 自媒体影视二创一站式工作台

**帧码宝** 是一款面向短视频创作者与短剧运营团队的 PC 端（Electron）工作台，把「素材采集 → 去重清洗 → 智能混剪 → 字幕配音 → 发布」整条链路整合到一个软件，帮你批量产出**不重复**的内容，规避平台查重与限流。

## 为什么选帧码宝

- **一站式**：采集、去重、混剪、字幕、配音、发布都在一个软件里；
- **多场景去重**：微信视频号去重、短剧去重、通用视频去重，覆盖主流平台规则；
- **批量产能**：每个成品不同随机种子，互不重复，一个人顶一支团队；
- **本地优先**：核心处理在本地完成，素材不外泄更安心；
- **硬件适配**：支持 N 卡 / Intel 核显硬件编码，自动回落 CPU。
