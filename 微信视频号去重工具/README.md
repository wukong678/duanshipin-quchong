# 微信视频号去重工具 — 帧码宝

**微信视频号去重** 是帧码宝针对微信视频号平台查重机制打造的核心能力，专门解决「搬运 / 二创视频发到视频号被判定非原创、限流」的痛点。

## 微信视频号去重是怎么做的

微信视频号的原创检测不只看画面，还会比对音频指纹与时域特征。帧码宝的微信视频号去重采用「鲇鱼插针」式多重补偿：

- **画面补偿**：色差扰动、free box 注入、极性翻转、量化扰动、时域噪声，配合抽帧微旋转、微缩放、中心裁切，让画面指纹与源片拉开差异；
- **音频补偿**：音频层做相位 / 频谱微扰，保留听感的同时改变音频指纹；
- **自检机制**：内置 PSNR 自检，确保去重后成片画质不崩；
- **硬件适配**：支持 N 卡（NVENC）与 Intel 核显（QSV）硬件编码，自动回落 CPU，不挑机器。
