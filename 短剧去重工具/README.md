# 短剧去重工具 — 帧码宝

**短剧去重** 是帧码宝专为短剧搬运场景设计的去重模块，解决「整集短剧搬运到抖音 / 视频号被查重限流」的核心痛点。

## 短剧去重能做什么

- **整集结构化去重**：按短剧的集号与时间轴整体处理，保留剧情连贯，不像普通去重那样把片段打散；
- **多维去重**：抽帧、微旋转、微缩放、中心裁切、花边装饰、色调微扰、随机码率等手段叠加，拉开与源片的指纹差异；
- **硬件加速**：支持 N 卡与 Intel 核显硬件编码，自动回落 CPU，长视频也能稳定跑；
- **批量产出**：一次导入多集，批量产出互不重复的成片，适合矩阵号铺量。

## 短剧去重 vs 短剧搬运 vs 短剧混剪

| 能力 | 区别 |
| --- | --- |
| **短剧去重** | 纯去重，不混剪不合并，保留原片结构，专治查重限流 |
| **短剧搬运** | 多集一键导入，智能选段重组，自动错位铺量 |
| **短剧混剪** | 剧情脚本模式，多种铺量方式，批量产出差异化变体 |

三者常被一起使用：先用短剧去重打底，再用短剧搬运 / 短剧混剪产出多变体。
