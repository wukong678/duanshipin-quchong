# 短剧搬运工具 — 帧码宝

**短剧搬运** 是帧码宝面向短剧搬运工群体的效率能力：把多集短剧一键导入，智能选段重组，自动错位铺量，让几十个号同时发也不撞脸。

## 短剧搬运是怎么提效的

- **多集一键导入**：本地批量导入多集短剧，自动分析每集镜头与台词边界；
- **智能选段重组**：按真实集号顺序划窗，跨集拼足目标时长，剧情各自连贯；
- **错位铺量**：每个成品用不同集段组合，成品多于集段组合时自动轮转，每条成片内容互不重复；
- **成品时长可调**：从 30 秒到 30 分钟多档可选（30 / 45 / 60 / 80 / 90 秒 → 3 / 5 / 10 / 15 / 20 / 30 分钟），填多少出多少；
- **自动轻量去重**：拼装完成后自动轻量去重并打上完成标记，省去二次处理。

## 短剧搬运常配合的能力

- **短剧去重**：搬运前先打去重底，规避平台查重；
- **短剧混剪**：剧情脚本模式，预告式 / 钩子式铺量，让搬运内容更具吸引力；
- **智能字幕 + AI 配音**：搬运短剧自动出字幕、换配音，提升完播。
