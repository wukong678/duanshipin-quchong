# 短剧混剪工具 — 帧码宝

**短剧混剪** 是帧码宝的剧情脚本智能混剪能力，专门服务于「短剧搬运后要做成吸引人的二创 / 混剪成片」这一环节，批量产出高完播、互不重复的变体。

## 短剧混剪的几种铺量方式

帧码宝的短剧混剪提供三种铺量方式，对应不同运营目标：

| 铺量方式 | 说明 |
| --- | --- |
| **标准** | 按默认方式出片，参数全随机、不撞脸 |
| **错位铺量** | 每个成品用不同集段组合，剧情各自连贯，适合发几十个号 |
| **钩子铺量** | 错位铺量 + 开场直入高能冲突，提升开头完播率 |

## 短剧混剪能产出什么

- **剧情脚本模式**：按真实集号顺序划窗，跨集拼足目标时长，成片剧情连贯；
- **成品时长多档**：30 / 45 / 60 / 80 / 90 秒 → 3 / 5 / 10 / 15 / 20 / 30 分钟，灵活适配不同平台；
- **自动轻量去重**：拼装后自动去重并打标记，成片即发；
- **智能后期**：智能字幕 + AI 配音 + 背景音乐 + 随机花边，一条龙产出；
- **批量产能**：每个成品不同随机种子，互不重复，一个人顶一支团队。

## 短剧混剪与短剧搬运 / 短剧去重的关系

- **短剧去重**：先给源片打去重底；
- **短剧搬运**：把多集素材选段重组、错位铺量；
- **短剧混剪**：在搬运基础上做剧情脚本级混剪与铺量，提升成片吸引力与完播。
