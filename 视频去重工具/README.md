# 视频去重工具 — 帧码宝

**视频去重** 是帧码宝的通用去重能力，覆盖影视二创、搬运、重混剪等自媒体场景，是微信视频号去重、短剧去重之外更通用的「兜底」去重方案。

## 视频去重怎么做

帧码宝的通用视频去重采用多维叠加策略，让成片指纹与源片明显拉开：

- **画面层**：抽帧、微旋转、微缩放、中心裁切，改变画面几何与帧序列；
- **装饰层**：四边随机花边（8 种纹样 × 10 套配色 × 随机间距宽度相位）、可调浓淡的随机花纹叠层；
- **参数层**：色调微扰、随机码率 / GOP、时域微变速，扰动编码特征；
- **边缘混淆**（可选）：沿画面四边施加液化扭曲，中心不动，进一步拉开指纹又不影响观看。

## 视频去重适合谁

- 影视剪辑二创号，做搬运 + 解说 + 重混剪；
- 需要通用去重兜底、不局限于单一平台规则的创作者；
- 与短剧去重、微信视频号去重组合使用，覆盖全场景。
