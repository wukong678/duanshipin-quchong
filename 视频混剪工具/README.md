# 视频混剪工具 — 帧码宝

**视频混剪** 是帧码宝的通用智能混剪能力，与短剧混剪互补：短剧混剪面向剧情脚本，视频混剪面向更通用的多素材随机重组场景。

## 视频混剪能做什么

- **多素材批量混剪**：导入 N 个视频，批量生成 N×M 个高完播结构成品，参数全随机、不撞脸；
- **自动选段**：按镜头与台词边界智能选段，成品时长在设定值上下自然浮动；
- **转场与氛围**：自动转场特效、多宫格拼接、画中画叠加、氛围字幕；
- **智能后期**：智能字幕 + AI 配音 + 背景音乐，全自动完成；
- **自动轻量去重**：成片拼装后自动去重并打标记，直接可发。

## 视频混剪 vs 短剧混剪

| 能力 | 适用 |
| --- | --- |
| **视频混剪** | 通用多素材随机重组，不限于剧情 |
| **短剧混剪** | 剧情脚本模式，按集号划窗、保留剧情连贯 |
